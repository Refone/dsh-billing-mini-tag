# dsh-billing-mini-tag

Current session spend (`¥x.xx`) next to the composer's cache-hit figure, priced from the [official DeepSeek token quote](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/).

  <br>
  <sub><em>see the ¥1.47, this is all you need</em></sub>
</p>

## Install

```sh
dsh plugin --profile web add github:Refone/dsh-billing-mini-tag
```

Refresh the Web GUI. Remove with:

```sh
dsh plugin --profile web remove dsh-billing-mini-tag
```
